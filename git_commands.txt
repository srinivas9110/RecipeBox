GIT COMMANDS USED IN THIS ASSIGNMENT (RecipeBox project)

git init
Starts version tracking in the current folder by creating a hidden .git directory.

git branch -M main
Forces the active branch to be called main.

git status
Lists changed, staged and untracked files in the working folder.

git status --short
Gives a condensed status with one short line per file.

git add <file>
Moves a file's current content into the staging area, ready for committing.

git commit -m "message"
Records the staged snapshot permanently, labelled with my message.

git branch feature
Makes a new branch named feature starting from the current commit.

git switch feature
Changes the checked-out branch to feature.

git switch main
Changes the checked-out branch back to main.

git merge feature
Combines the history of feature into whichever branch is checked out.

git log --oneline --graph --decorate --all
Draws every branch's history as a compact graph, labelling commits with branch names.

git log --oneline
Lists the commits of the current branch, one per line.

git check-ignore -v <path>
Tells me whether a path is ignored and which ignore-file line is responsible.

git revert --no-edit HEAD
Creates a fresh commit that cancels the latest one, skipping the message editor.

git remote add origin <URL>
Saves the GitHub address under the nickname origin.

git remote -v
Prints the saved remote nicknames together with their URLs.

git push -u origin main
Sends main to GitHub and links local main to origin/main.

git push -u origin feature
Sends feature to GitHub and links it to origin/feature.

git push
Sends new commits from the current branch to its linked remote branch.
